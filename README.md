# Portfolio website

This is the portfolio website of Thijs Lander. Deployed at [thijslander.com](https://thijslander.com)
This repo is published under MIT license. Have fun!

The following tech was used for building this website:

- Web framework - [Next.js](https://nextjs.org/) with [React](https://react.dev/) and [TypeScript](https://www.typescriptlang.org/)
- Deployment platform - [Vercel](https://vercel.com)
- Build system - [Turborepo](https://turborepo.dev/)
- Styling - [Tailwind.css](https://tailwindcss.com/)
- Headless CMS - [Contentful](https://www.contentful.com/)
- Query language - [GraphQL](https://graphql.org/)
- Animations - [Motion.dev (previously Framer Motion)](https://motion.dev/)
- Headless components - [HeadlessUI](https://headlessui.com/)
- Icons - [Radix icons](https://www.radix-ui.com/icons)
- Runtime validation - [Valibot](https://valibot.dev/)
- Linter - [Oxlint](https://oxc.rs/docs/guide/usage/linter.html)
- Formatter - [Oxfmt](https://oxc.rs/docs/guide/usage/formatter.html)
- IDE - [Zed](https://zed.dev/)
